# Живые цивилизации — сборка через GitHub

## Как получить JAR без программирования
1. На GitHub нажми **New repository** и создай репозиторий `living-civilizations`.
2. Распакуй этот архив на компьютере.
3. В репозитории выбери **Add file → Upload files**.
4. Загрузи всё содержимое распакованной папки, включая папку `.github`, затем нажми **Commit changes**.
5. Открой вкладку **Actions**. Сборка должна стартовать после загрузки. Если нет — выбери **Build Minecraft Mod → Run workflow**.
6. Дождись зелёной галочки у запуска. Открой его и найди раздел **Artifacts**.
7. Скачай `living-civilizations-forge-1.20.1`, распакуй ZIP и возьми из него `.jar`.
8. Положи JAR в `%appdata%\.minecraft\mods` и запусти профиль Forge для Minecraft 1.20.1.

Нужна Java 17 в среде сборки (GitHub Actions настроен на неё), а в лаунчере — Forge 1.20.1.

Важно: это начальный каркас с предметом «Посох путника», а не готовая версия с NPC, дорогами и королевствами.
