# Живые цивилизации 0.2.0 — Forge 1.20.1

Добавлено:
- Посох путника с собственной 16x16 текстурой.
- Первый NPC — путешественник на модели жителя Minecraft.
- Яйцо призыва путешественника в творческой вкладке «Яйца призыва».
- Путешественник самостоятельно бродит, смотрит на игрока и осматривается.

## Обновление GitHub
Загрузи содержимое архива в свой репозиторий поверх старых файлов, разреши замену файлов и нажми Commit changes. Важно загрузить скрытую папку `.github` и все файлы из `src`. Затем открой Actions. После успешной сборки скачай Artifact, распакуй и положи JAR в `.minecraft/mods`.

Требования: Minecraft Java 1.20.1, Forge 47.x, Java 17.
