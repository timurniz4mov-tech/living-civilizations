# Живые цивилизации 0.6.0-beta — Minecraft Java 1.20.1 / Forge 47.2.0

## Исправления поселений и дорог
- Автогенерация поселений теперь проверяет место каждые 10 секунд; расстояние между центрами сокращено с 560 до 320 блоков.
- Место выбирается в пределах 20–34 блоков от игрока (для ручной команды — 12–24 блока), а не на расстоянии 84–168 блоков в потенциально незагруженных чанках.
- Генератор проверяет, что все изменяемые чанки уже загружены. Это исправляет частую причину, из-за которой деревня вообще не появлялась.
- Разрешён небольшой уклон местности: площадь выравнивается перед строительством.
- Дороги — отдельные низкие блоки высотой 1/8 блока; у них есть модели и текстуры. Они размещаются на уровне поверхности земли, а не в воздухе.
- Для каждого материала доступны два вида: тонкая дорога высотой 1/8 блока и полный куб. Все шесть вариантов находятся в творческой вкладке «Строительство».
- Для ручной генерации можно ввести `/civilizations settlement`.

## Поселение включает
- Четыре деревянных дома с дверями, окнами, кроватями и сундуками.
- Колодец, рыночный навес и ферму.
- Гравийные главные дороги, грязные боковые тропинки и мощёную центральную площадь.
- Торговцев, работягу, стражников и путешественника.
- Каждое поселение регистрируется как отдельная территория королевства; часть поселений получает небольшую крепость и королевский двор.

## Средневековые скины
GitHub Actions скачивает 64x64 PNG-скины из подборки NameMC «Medieval» и «Adventurer» и назначает отдельный скин каждой роли NPC. Четыре предоставленные тобой текстуры используются как резервные для части ролей; для остальных остаются резервные скины из предыдущей версии. Если NameMC ограничит загрузки, сборка сохранит встроенные текстуры. Источники и страницы скинов указаны в `SKINS_SOURCES.md`.

## Команды
- `/civilizations settlement` — построить поселение неподалёку.
- `/civilizations roads dirt <длина>` — проложить грязную дорогу.
- `/civilizations roads gravel <длина>` — проложить обычную гравийную дорогу.
- `/civilizations roads paved <длина>` — проложить тонкую мощёную дорогу.
- `/civilizations roads dirt_full <длина>` — проложить полноразмерную грязную дорогу.
- `/civilizations roads gravel_full <длина>` — проложить полноразмерную гравийную дорогу.
- `/civilizations roads paved_full <длина>` — проложить полноразмерную мощёную дорогу.
- Для тонких дорог доступны суффиксы `_half`: `dirt_half`, `gravel_half`, `paved_half`.
- `/civilizations kingdom create <название>` — создать своё королевство.
- `/civilizations war <название>` — объявить войну.
- `/civilizations peace <название>` — заключить мир.
- `/civilizations conquer <название>` — захватить столицу в радиусе 100 блоков во время войны.
- `/civilizations map` — показать список королевств и их территории.
- `/civilizations castle` — построить небольшую крепость.

## Обновление GitHub
1. Распакуй архив.
2. В репозитории выбери **Add file → Upload files**.
3. Загрузи всё содержимое поверх старого проекта, обязательно включая `.github`, `scripts` и `src`.
4. Нажми **Commit changes**.
5. Во вкладке **Actions** открой новый запуск **Build Minecraft Mod**.
6. После зелёной галочки скачай Artifact `living-civilizations-forge-1.20.1`.
7. Распакуй Artifact ZIP и положи JAR в `%appdata%\.minecraft\mods`.

## Проверка в существующем мире
После установки нового JAR подожди до 30 секунд — мод попытается создать поселение рядом с игроком и покажет сообщение в чате. Для немедленного теста введи `/civilizations settlement` (нужны читы/права оператора). Если генератор не найдёт подходящей площадки, попробуй команду на равнине.

Требования: Minecraft Java 1.20.1, Forge 47.x, Java 17. Я не могу запустить сам Minecraft в этой среде, поэтому после загрузки проекта нужна зелёная сборка GitHub Actions и проверка в игре.


## Новое в 0.6.0-beta
- Поселения могут появляться чаще: попытка генерации каждые 10 секунд, минимальная дистанция между центрами уменьшена.
- В каждом поселении два работяги; работяги могут один раз достроить небольшой деревянный дом рядом с поселением.
- Разбойники нападают на игроков, торговцев, путешественников, рабочих, стражников и знать; стражники и воины распознают разбойников как врагов.
- Оружие и инструменты теперь видны в руках: у разбойника железный топор и щит, у стражника меч и щит, у воина меч, у работяги кирка и топор.
- Добавлены полноразмерные варианты дорог; тонкие дороги сохранены.
- Скины загружаются из NameMC через GitHub Actions.

## Команды дорог
Синтаксис: `/civilizations roads <type> <length>`.
Типы: `dirt`, `gravel`, `paved` (старые короткие названия для тонких дорог), `dirt_half`, `gravel_half`, `paved_half`, `dirt_full`, `gravel_full`, `paved_full`.


## Исправление 0.6.1-beta
Исправлена совместимость конструктора `HumanoidArmorLayer` с Minecraft 1.20.1 / Forge 47: добавлен обязательный `ModelManager` из renderer context. Рендерер предметов в руках NPC сохранён.


## Новое в 0.7.0-beta
- Полные дороги: `dirt`, `gravel`, `paved` теперь цельные кубы. Тонкие дорожки: `dirt_half`, `gravel_half`, `paved_half`.
- При прокладке по воде/пустоте RoadBuilder создаёт каменную опору до твёрдого дна; дороги не обрываются на воде.
- Мини-карта открывается клавишей M или предметом «Карта королевств». На ней показаны рельеф/вода, центры поселений, границы королевств и красным — земли с активной войной.
- Боевой AI разбойников перенесён в конструктор после инициализации роли. Разбойники ищут мирных NPC и игроков, а стража/воины — разбойников. Есть дополнительный поиск цели каждые 15 тиков.
- Работягов не менял в этой версии: их уже добавленная попытка строить дом оставлена как была.

### Команды дорог
- `/civilizations roads dirt 20` — полная грязная дорога.
- `/civilizations roads gravel 20` — полный гравийный блок.
- `/civilizations roads paved 20` — полная мощёная дорога.
- `/civilizations roads dirt_half 20` — тонкая грязная дорожка.
- `/civilizations roads gravel_half 20` — тонкая гравийная дорожка.
- `/civilizations roads paved_half 20` — тонкая мощёная дорожка.

### Мини-карта
- Нажми **M** — запросить карту у сервера и открыть экран.
- Предмет «Карта королевств» также открывает экран карты.
- Синим показываются земли королевств, красным — территории тех, кто находится в состоянии войны. Золотые маркеры — центры поселений/королевств, красный крест — позиция игрока.


## Управление в версии 0.7.0-beta
- **M** — открыть мини-карту ближайшей местности и территорий королевств.
- Предмет **«Карта королевств»** — открыть тот же экран.
- `dirt`, `gravel`, `paved` — дороги полными кубами.
- `dirt_half`, `gravel_half`, `paved_half` — тонкие дорожки.
- При прокладке на воде/в пустоте создаётся каменная опора до твёрдого основания.

Если в старом мире дорога уже была размещена предыдущей версией, сломай и поставь её заново, чтобы обновлённая форма блока появилась корректно.


## Важное уточнение по карте
Мини-карта открывается клавишей **M**. Она показывает загруженную местность вокруг игрока (локальный обзор), а сервер передаёт ей координаты всех зарегистрированных поселений/королевств и состояние войны. Нажатие на предмет «Карта королевств» открывает тот же экран.
