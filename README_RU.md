# Живые цивилизации 0.3.0-beta — Minecraft Java 1.20.1 / Forge

## Что находится в проекте
- 9 типов NPC с человекоподобной моделью игрока Minecraft и отдельными скинами: путешественник, караванный торговец, деревенский торговец, работяга, стражник, воин, лорд, король, разбойник.
- Яйцо призыва для каждого NPC.
- Базовое поведение: ходьба, осмотр игрока; стражники и воины сражаются с монстрами; разбойники нападают также на игроков.
- Торговцы обменивают изумруды на хлеб (караванный — 2 изумруда, деревенский — 1).
- Посох путника с собственной текстурой.
- Три дороги: грязная, гравийная и мощёная.
- Периодическое появление путников/торговцев/работников/стражников рядом с игроком, небольших поселений с домами и дорогами, а также лагерей разбойников.
- Периодическая генерация каменных крепостей с королём, лордом и стражей; крепость регистрирует нейтральное королевство на политической карте.
- Сохранение королевств в мире, карта-книга и команды создания королевства, объявления войны и мира.
- Команда строительства небольшой крепости.

## Команды
Названия королевств в командах вводи одним словом, используй `_` вместо пробелов.
- `/civilizations kingdom create <название>` — создать королевство с центром у игрока.
- `/civilizations kingdom war <название>` — объявить войну другому королевству.
- `/civilizations kingdom peace <название>` — заключить мир.
- `/civilizations conquer <название>` — захватить столицу вражеского королевства (нужно объявить войну через `/civilizations kingdom war <название>` и подойти к центру ближе 100 блоков).
- `/civilizations map` — список королевств и их границ.
- `/civilizations castle` — построить небольшую крепость вокруг игрока.
- `/civilizations roads dirt <длина>` — проложить грязную дорогу.
- `/civilizations roads gravel <длина>` — проложить обычную дорогу.
- `/civilizations roads paved <длина>` — проложить мощёную дорогу.
- Карта королевств при использовании показывает государство под игроком.

## Как обновить GitHub
1. Распакуй архив.
2. Открой свой репозиторий и выбери Add file → Upload files.
3. Загрузи всё содержимое поверх предыдущих файлов, обязательно включая скрытую папку `.github`.
4. Нажми Commit changes.
5. Открой Actions. После зелёной галочки открой запуск и скачай Artifact `living-civilizations-forge-1.20.1`.
6. Распакуй Artifact ZIP и положи JAR в `%appdata%\.minecraft\mods`.
7. Запусти Minecraft Java 1.20.1 с Forge 47.x.

## Честное примечание о полноте
Это крупная первая сборка игрового каркаса, а не AAA-симулятор: королевства пока создаются командами, война сохраняется как дипломатическое состояние, а захват территорий и профессии пока имеют базовое поведение. Нужна проверка сборки GitHub Actions и тест в реальном Minecraft. Война пока является дипломатическим состоянием, а захват столицы выполняется командой рядом с центром; автоматические армии и самостоятельные решения AI-королей ещё не реализованы.
